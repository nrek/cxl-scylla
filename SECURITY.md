# Security policy

Scylla is pre-release software. No release is currently designated for long-term security support.

## Reporting a vulnerability

Please do not open a public issue for a vulnerability that could expose files, credentials, processes, or network access.

Use the repository host's private security-advisory feature when available. Include the affected commit, Windows version, reproduction steps, and sanitized diagnostics.

See [scyllagpt/docs/lockdown.md](scyllagpt/docs/lockdown.md) for Workbench security controls and known limitations.
