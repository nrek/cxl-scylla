# Security policy

Scylla is pre-release security software. No release is currently designated for long-term security support.

## Reporting a vulnerability

Please do not open a public issue for a vulnerability that could expose files, credentials, processes, or network access.

Use the repository host's private security-advisory feature when available. Include the affected commit, Windows version, target application type, reproduction steps, and sanitized diagnostics.

See [docs/security-model.md](docs/security-model.md) for the intended boundary and known limitations.
